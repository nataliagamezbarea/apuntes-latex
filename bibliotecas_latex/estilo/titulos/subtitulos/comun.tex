% =====================================================================
%  COMUN.TEX — lo que comparten los subtitulos
%  Un subtitulo va DENTRO de una seccion: por eso no lleva las barras
%  de \seccion.
%
%  Su color:
%    * es de la MISMA paleta que el titulo (el color de la seccion)
%    * pero un escalon mas claro que el titulo, sin llegar a lavarse:
%      se oscurece con negro en vez de aclararse con blanco, porque
%      mezclar con blanco dejaba los subtitulos casi invisibles en las
%      paletas claras (celeste, amarillo, lima...).
%    * 68% color + 32% negro -> contraste ~4,5:1 o mas con el papel.
% =====================================================================

% el color del subtitulo = el de la seccion, un escalon mas claro
\newcommand{\subtitulocolor}{\coloractual!68!black}
